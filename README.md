
# MatrixLab — Geometric Transformations Visualizer

MatrixLab is a Python-based project for exploring linear algebra concepts through geometric transformations and visualizations.

The project focuses on understanding how matrices can be used to transform objects in 2D and 3D space.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Google Colab

## Project Modules

### 1. 2D Geometric Transformations — Completed

A visualizer that applies geometric transformations to a 2D shape using matrices and homogeneous coordinates.

**Features:**
- Rotation
- Scaling
- Translation
- Reflection across the x-axis and y-axis
- Shearing along the x-axis and y-axis
- Multiple transformations in a user-defined sequence
- Combined transformation matrices
- Step-by-step visualization of transformation stages
- Verification of combined and sequential transformations

### 2. 3D Geometric Transformations — Planned

Extend the project to three-dimensional objects using 4×4 homogeneous transformation matrices.

**Planned features:**
- 3D object visualization
- Translation and scaling in 3D
- Rotation around the x, y, and z axes
- Composite 3D transformations

### 3. Perspective Projection — Planned

Explore how three-dimensional objects can be projected onto a two-dimensional viewing plane using linear algebra.

## How to Run

1. Open the desired `.ipynb` notebook in Google Colab.
2. Run the notebook cells.
3. Modify the transformation sequence and parameters to experiment with different results.
4. Observe the transformed coordinates, matrices, and visualizations.
